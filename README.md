# Conor’s TiSiM Tools

A collection of visual tools for touchscreens, iPhone, iPad and desktop.

- **Timers:** [Choose a timer](./timers/) — 5 minutes, 15 minutes, 30 minutes or 1 hour
- **Communication:** [My Feelings Board](./communication/feelings/) — an interactive feelings thermometer

All timers keep their original addresses at `/5min/`, `/15min/`, `/30min/` and `/1hour/`.

The feelings board saves uploaded photos in browser storage on the device; it does not sync them between devices.

Site: https://stan602-bot.github.io/tisimtools/
